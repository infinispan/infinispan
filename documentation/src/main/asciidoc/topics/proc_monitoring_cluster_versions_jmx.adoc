= Monitoring {brandname} versions across the cluster

The Transport MBean exposes the version that each cluster member runs.
Use these attributes to verify that every expected member is present and runs the target version, for example before you continue an in-place rolling upgrade.

.Procedure
. Connect to {brandname} with any JMX capable tool, such as JConsole, and navigate to the following object:
+
[source,text,options="nowrap",subs="attributes+"]
----
org.infinispan:type=CacheManager,name="default",component=Transport
----
+
. Read the `clusterMemberVersions` attribute to get the version of each member.
+
The attribute is a map that holds the `major.minor.patch` version of every member, keyed by the logical address of the member.
+
. Read the `mixedVersionCluster` attribute to find out whether the members run different versions.
+
The attribute is `true` when the members of the cluster do not all run the same version.

[NOTE]
====
{brandname} reads both attributes from the local cluster view, where every member address carries the version of the node that it identifies.
Reading the attributes does not send a cluster wide request, and the values change as soon as a new view is installed.

A cache manager that runs without a transport does not have a Transport MBean.
====
