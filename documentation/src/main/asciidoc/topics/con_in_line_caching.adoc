= In-line caching

{brandname} handles all application requests for data that resides in persistent storage.

With in-line caches, {brandname} uses cache loaders and cache stores to operate on data in persistent storage.

* Cache loaders provide read-only access to persistent storage.
* Cache stores provide read and write access to persistent storage.

.In-line caches
[plantuml, target=in-line-caching-flow, format=svg, align=center, subs="attributes+"]
....
@startuml
skinparam defaultFontName sans-serif
skinparam shadowing false
skinparam sequenceMessageAlign center

actor "Applications" as App
participant "{brandname}\ncluster (cache)" as C
database "Persistent\nstorage" as PS

== Read through a cache loader ==
App -> C : Read K1
C -> PS : Load K1 via the\ncache loader
PS --> C : K1
C --> App : K1

== Write through a cache store ==
App -> C : Put K2
C -> PS : Store K2 via the\ncache store
@enduml
