= Executing code in the grid

[role="_abstract"]
The main benefit of a cache is the ability to very quickly lookup a value by its key, even across machines.
In fact this use alone is probably the reason many users use {brandname}.
However {brandname} can provide many more benefits that are not immediately apparent.
Since {brandname} typically runs in a cluster, it provides features that help you use the entire cluster to process workloads.
