= Migrating data with Hot Rod
Migrate data between {brandname} clusters running different versions
without downtime or data loss using the Hot Rod protocol.

The Hot Rod migration process involves setting up a target cluster running the new version, connecting it to the source cluster via a remote cache store, switching clients to the target cluster, synchronizing data, and finally decommissioning the source cluster.

The following diagram illustrates the interaction between the source cluster, target cluster, and client applications during the migration process.
